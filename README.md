# Polaris Public Technical Review

Polaris is a research program for evidence-conservative reconstruction and
evaluation of publicly documented AI incidents.

## Start a review

- [Provenance](docs/public-review/provenance.md)
- [Reproducibility](docs/public-review/reproducibility.md)
- [AI incident method](docs/public-review/incident-method.md)
- [Evaluation and audit](docs/public-review/evaluation.md)

Read the [reviewer package boundary](docs/public-review/README.md) and
[Claims Boundary](docs/public-review/CLAIMS_BOUNDARY.md) first.

Estimated reading time: **10–15 minutes** for one specialist path.

This public package does not contain the private evidence dependency closure
and does not support independent evidence verification or deterministic
reproduction. Review participation is not endorsement.
