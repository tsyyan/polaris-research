# Security Policy

Polaris is research software and documentation. It carries no production
deployment, operational security, availability, or fitness guarantee.

## Reporting a Vulnerability

Please report suspected security vulnerabilities responsibly through GitHub's
private vulnerability reporting channel for this repository when available.
If that channel is unavailable, contact the repository owner privately through
their GitHub profile before disclosing exploit details.

Include the affected commit or release, impact, reproduction steps, and any
suggested mitigation. Do not place secrets, personal data, raw evidence, or
working exploit details in a public issue.

## Scope

Security reports may cover the published release tooling, unsafe handling of
untrusted content, accidental information disclosure, or dependency-related
risks visible in this repository.

A report being accepted for review does not imply production readiness or a
security certification.
