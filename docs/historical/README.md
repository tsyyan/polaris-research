# Historical Research Material

This directory marker explains how to read older material that remains in the repository.

Earlier public-review and outreach documents focused primarily on **evidence-conservative reconstruction of publicly documented AI incidents**. That work is part of the history of NOESIS and is retained for provenance rather than rewritten to match the current research emphasis.

The current primary public track is the bounded autonomous-agent control/evidence program described in the root [`README.md`](../../README.md), [`RESEARCH_STATUS.md`](../../RESEARCH_STATUS.md), and [`TECHNICAL_ARCHITECTURE.md`](../../TECHNICAL_ARCHITECTURE.md).

Historical documents may use older project framing, milestone language, reviewer instructions, or claims boundaries appropriate to their original snapshot. They should not be read as the current roadmap unless the root status ledger explicitly links them as current evidence.

Retention is intentional: NOESIS favors append-only research history and visible changes of direction over silently replacing older artifacts with a cleaner retrospective narrative.
