# Polaris Outreach Package v1.0

This package is the first external research introduction to Polaris. It is
intended for technical review, not marketing, fundraising, procurement, or a
request to adopt the project.

**Naming:** Polaris is the public-facing research program; **NOESIS** is the
repository and implementation that hosts and supports that work. They are not
separate projects.

4. [Technical FAQ](FAQ.md)
5. [Why Polaris exists](WHY_POLARIS.md)
6. [Cover letter](COVER_LETTER.md)

[ADR-038](../architecture/ADR-038-milestone-2-closure.md). The current
Milestone 3 activity, Pilot-001, is planned research and is not presented as a
completed result.
