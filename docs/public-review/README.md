# Polaris Minimal Public Reviewer Package

Package version: **1.0.0**

Polaris is a research program for evidence-conservative reconstruction and
evaluation of publicly documented AI incidents. The private NOESIS repository
hosts the complete workflow. This package is a bounded public projection for
technical review; it is not the private repository or its evidence closure.

## Current status

Milestone 2 is complete within its declared local experimental trust model.
Pilot-006 recorded a `PASS` disposition for its preregistered mechanical
workflow. Read [Claims Boundary](CLAIMS_BOUNDARY.md) before interpreting that
status.

## Review boundary

Publicly inspectable materials are the files in this package and the
architecture documents linked from them. The
[Pilot-006 Public Record](PILOT_006_PUBLIC_RECORD.md) is a projection of
policy-approved facts. The [Private Artifact Index](PRIVATE_ARTIFACT_INDEX.json)
publishes identity metadata only for selected canonical artifacts.

Private experiment records, execution evidence, sealed artifacts, raw source
content, research corpora, internal memory, and private Git history are not
publicly disclosed. Their hashes do not make their content inspectable, and
this package does not support independent evidence verification or
deterministic reproduction of Pilot-006.

## Feedback

Submit a public GitHub issue using the
[Review Response Template](REVIEW_RESPONSE_TEMPLATE.md), or use the contact
route in the public review invitation. State which unavailable materials
limited the review.

Review participation is not endorsement. Feedback may be bounded, critical,
inconclusive, or blocked by unavailable evidence.
